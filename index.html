Welcome to Aksikontal

Aksikontal is an independent learning project exploring ideas related to gravity, motion, energy, electricity, and probability.

About the Project

This project organizes questions, definitions, and mathematical ideas into a framework for further study. It is a work in progress, not an established scientific theory.

Scientific Status

Some equations and concepts discussed here are already part of established physics. Any new claims require clear predictions, reliable experiments, comparison with existing research, and independent review.

The Manuscript

The Aksikontal manuscript is being developed. Further chapters, references, and revisions will be added as the project progresses.
